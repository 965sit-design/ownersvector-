# ベクトルシート

Excelで作成していた商談議事録を、ブラウザ上で記録・確認・PDF保存するためのHTMLアプリです。顧客情報や商談内容はブラウザ内の永続保存領域へ保存せず、ページを開いている間だけJavaScriptメモリ上で一時保持します。

## 起動方法

依存パッケージやビルドは不要です。任意のローカルWebサーバーでこのフォルダを配信してください。

```powershell
cd C:\Users\965si\Documents\code\housing-meeting-minutes-prototype
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。

## 商談シートを作る

1. 開始画面の「新規入力」を押します。
2. お施主様名、商談日、商談回数を入力します。商談タイトルは任意です。
3. 「空の商談シートを作成」を押します。
4. 現在のご状況、計画時期・建築理由、予算、建物、土地、奥様、ご主人様、ご両親の各欄へ記録します。
5. 後日編集する場合は「実務者用CSVを書き出す」からCSVを保管します。

主要4項目は、文章のほかJPEG・PNG・WebP画像を添付できます。1画像の上限は10MBです。画像はページを開いている間だけ一時的に扱います。CSVには画像本体を含めません。

## 画面と機能

- 開始画面：新規入力、または実務者用CSVの読み込みから開始します。
- 入力モード：基本情報、主要4項目、関係者別補足、任意の補足項目、画像を編集します。
- 社内用振り返り：すべての項目をまとめて確認します。空欄は「未入力」と表示します。
- お客様用プレビュー：主要4項目だけを選択し、共有文面を調整します。表示対象が0件のときは入力モードへの案内を表示します。
- 印刷・PDF保存：お客様用プレビューをブラウザの印刷機能からPDFへ保存します。
- 実務者用CSV書き出し：後日編集用のCSVを明示的に保存します。
- 実務者用CSV読み込み：保管済みCSVから内容を復元して編集を再開します。
- 現在の入力内容を破棄：フッターのボタンから、ページ上の一時データを破棄します。

## 保持・保存仕様

サーバーへの送信は行いません。ブラウザ内の永続保存領域にも保存しません。

- 入力中の文章・シート情報：ページ表示中のJavaScriptメモリのみ
- 添付画像本体：ページ表示中のJavaScriptメモリのみ
- 後日編集用データ：利用者が明示的に書き出した実務者用CSVのみ
- 初期状態：空の開始画面

localStorage、sessionStorage、IndexedDB、Cookie、Cache Storage、URLクエリ、URLハッシュによる自動保存・自動復元は行いません。ページを再読み込みした場合、入力内容は復元されません。後日編集する場合は、実務者用CSVを読み込んでください。

